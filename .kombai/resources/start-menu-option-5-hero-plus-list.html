Key idea: Create visual hierarchy by splitting the menu into two tiers. The top "Pinned" section shows 4 hero-sized Carbon ClickableTiles for the most important destinations (Platforms, Audio Grid, MIDI Hub, Artifacts) with descriptions and navigation arrows. Below, a compact 3-column micro-grid shows all remaining workspaces as small icon+label pills. This is the Windows 10/11 Start Menu pattern — prominent pinned items at top, full catalog underneath. Pinned items could be user-configurable (the data model already supports pinnable).
