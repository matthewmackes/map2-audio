Key idea: Replace the icon grid with a vertical contained list grouped by category. Each item shows icon + label + short description + navigation arrow. Categories have sticky section headers. Extremely light-theme friendly because it uses Carbon's ContainedList surface tokens instead of custom icon frames. Compact and scannable — ideal for menus with 10+ items.
