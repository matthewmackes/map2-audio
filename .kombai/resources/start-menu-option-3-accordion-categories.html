Key idea: Group items into collapsible accordion sections by category (Audio Grid, MIDI, Hardware, AVB). Each section header shows item count. Categories like Hardware and AVB can default to collapsed since they're less frequently used. This reduces visual noise, makes the menu shorter, and adds clear information hierarchy. Uses Carbon's Accordion component directly. Works well as the item count grows.
