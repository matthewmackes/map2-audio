## 🎯 Component Color Scheme

### BrandingPanel (Header)
```
Background: Linear gradient (manufacturer color @ 20% opacity)
Left Border: Solid manufacturer color (4px)
Logo Color: Full brand color
Text: Manufacturer color for labels, dark for headers
Link: Manufacturer color with underline hover
```

Example (Dell):
```
Background: linear-gradient(135deg, #0066CC20 0%, #F4A51D20 100%)
Border-Left: 4px solid #0066CC
Logo: Full Dell blue
Title: #0066CC
Support Link: #0066CC with underline on hover
```

### HealthMonitor (Status Cards)
```
Excellent:  Badge bg #D1FAE5, text #065F46, icon #10B981
Good:       Badge bg #DBEAFE, text #0C4A6E, icon #3B82F6
Warning:    Badge bg #FEF3C7, text #78350F, icon #F59E0B
```

## ✨ Animation & Transitions

### Hover Effects
```
Card:              Shadow deepens, slight lift (transform: translateY(-2px))
Button:            Background color shift, shadow increase
Link:              Text color change + underline animation
Badge:             Slight scale (1.05x)
Chart:             Opacity fade in on load
```

### Loading States
```
Skeleton loader:   Gradient shimmer effect
Spinner:           Material-UI CircularProgress (manufacturer color)
Update animation:  Fade in new values (300ms transition)
```

### Timing
```
Hover:             150ms ease
Transitions:       300ms ease
Chart animations:  500ms ease-out
Refresh animation: 1000ms ease
```

## 🎬 Interaction States

### Buttons
```
Default:   Background: rgba(0,0,0,0.05), Border: 1px solid rgba(0,0,0,0.1)
Hover:     Background: rgba(0,0,0,0.1), Cursor: pointer
Active:    Background: rgba(0,0,0,0.15), Shadow: inset 0 2px 4px
Disabled:  Opacity: 0.5, Cursor: not-allowed
Loading:   Icon spinning, text dimmed
```

### Tabs/Accordions
```
Inactive:  Background: transparent, Border-bottom: 2px solid transparent
Active:    Background: rgba(color,0.05), Border-bottom: 2px solid color
Hover:     Background: rgba(color,0.1)
```

## 🔗 Design System References

Consistent with:
- **Material-UI** - Component library
- **Lucide React** - Icons
- **MAP2 Audio theme** - Dark mode support, existing color palette
- **Hardware manufacturer** - Brand colors (Dell, Lenovo, HP)

---

**All dimensions and colors are flexible** and should adapt based on theme settings and user preferences.
