# Workspace Catalog Storefront Reference

This document is the customer-facing reference brief for the `/platforms/workspace-catalog` storefront. It gives each launcher a concise MAP2 positioning note so the storefront can link to a real document that references the workspace directly.

## Core Workspaces

### Platforms
- Route: `/platforms/overview`
- Positioning: The supervisory MAP2 entry point for platform posture, node visibility, and cross-workspace navigation.

### Audio Artifacts
- Route: `/artifacts`
- Positioning: The unified catalog for plugins, NAM captures, IRs, SoundFonts, and native JUCE processors.

### Stage Mode
- Route: `/perform`
- Positioning: The performance-oriented runtime surface for live preset recall and stage-safe operation.

### Tesira AVB
- Route: `/tesira`
- Positioning: The Biamp Tesira fleet, DSP, and AVB operations surface inside MAP2.

### Push Surface
- Route: `/labs/push-surface`
- Positioning: The dedicated Ableton Push programming and live-feedback workspace.

### MPX1 Rack
- Route: `/mpx1`
- Positioning: The Lexicon MPX-1 control, library, and diagnostic workflow within MAP2.

### IntelFX Rack
- Route: `/intelfx`
- Positioning: The Rocktron Intellifex editing and preset-control workspace.

### Ground Control Pro
- Route: `/ground-control-pro`
- Positioning: The SysEx import, validation, backup, and transmit workspace for the Ground Control Pro.

Fixed desktop Start Menu tiles such as `Brain`, `Audio Grid`, `MIDI Hub`, and `Audio Interfaces` remain accessible from the shell, but they are intentionally not listed here because they are no longer Workspace Catalog entries.

Platform utility workspaces such as `Workspace Catalog`, `Audio Engine`, `Management`, `AVB Routing`, `Network Discovery`, `Cluster Dashboard`, `Adoption`, `Host Machine`, `Theme`, and `Platform Guide` remain available inside the routed Platforms shell, but they are intentionally not listed here because they are no longer standalone Workspace Catalog entries.

## Hardware And Interface Workspaces

### Maschine MK1
- Route: `/maschine`
- Positioning: The daemon, LCD, LED, encoder, and HID-diagnostics workspace for Maschine MK1.

### Edirol UA-1000
- Route: `/edirol-ua1000`
- Positioning: The interface-specific control and status page for the Edirol UA-1000.

### HoTone JoGG
- Route: `/hotone-jogg`
- Positioning: The connection-state and device-control surface for the HoTone JoGG profile.

### Generic Interface
- Route: `/hotone-jogg`
- Positioning: The experimental fallback profile layered on the shared interface-control workflow.

### LCD Console
- Route: `/lcd`
- Positioning: The external display and hardware-panel surface shown in the storefront as Hardware Not Detected until the required path is present.
