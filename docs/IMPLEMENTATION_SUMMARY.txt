================================================================================
IMPLEMENTATION ARCHITECTURE
================================================================================

Featured Amps Flow:
  User Request
    ↓
  FeaturedAmpsManager.discover_and_download_featured_amps()
    ↓
  Query TONE3000 API for top 7 amps
    ↓
  For each amp, fetch top 3 variants
    ↓
  Download .nam files
    ↓
  Generate standardized names
    ↓
  Register in database (is_featured=true)
    ↓
  Database commit (transactional)
    ↓
  Return results

Bulk Rename Flow:
  User Request
    ↓
  NAMBulkRenamer.scan_library()
    ↓
  Scan all NAM directories recursively
    ↓
  Calculate hashes for deduplication
    ↓
  NAMBulkRenamer.enrich_metadata()
    ↓
  Cross-reference database records
    ↓
  Cross-reference GitHub repository
    ↓
  Analyze filenames for patterns
    ↓
  NAMBulkRenamer.preview_renames() or execute()
    ↓
  For each file (dry-run or actual):
    - Generate new name
    - Check for conflicts
    - Move file (if execute)
    - Update database (if execute)
  ↓
  Save audit log
    ↓
  Return results

================================================================================
ERROR HANDLING
================================================================================

All operations include:

- Transactional Safety: Database changes rolled back on any error
- Duplicate Detection: Hash-based, prevents file duplication
- Path Validation: Checks for filename conflicts before rename
- Permission Checking: Validates write permissions upfront
- Error Tracking: Detailed messages for all failures
- Graceful Fallbacks: Continues on non-critical errors
- Audit Logging: All operations logged regardless of outcome
- Rollback Capability: Can revert operations with audit trail

Common Issues & Solutions:
  ✅ Database columns missing → Run migration script
  ✅ TONE3000 not available → Skip featured, use bulk rename
  ✅ Permission denied → Fix ownership with chown
  ✅ Filename conflicts → Dry-run shows all conflicts first
