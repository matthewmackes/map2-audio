## What NOT to Buy (Red Flags)

❌ **Avoid:**
- Anything requiring proprietary Windows software
- USB 1.1 interfaces (too old)
- Interfaces with "FireWire only" (unless you have FW card + FFADO)
- Broken/damaged units unless you can test/repair
- Anything over $150 (defeats the budget)

✅ **Safe Bets:**
- Class-compliant USB 2.0
- ADAT expanders (driver-free)
- "Untested" from reputable sellers (often fine, just not tested)
- Older Focusrite/MOTU (proven Linux compatibility)
