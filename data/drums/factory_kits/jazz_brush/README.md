# Jazz Brush

Purpose-generated brush-oriented jazz kit with soft cymbals and room accents.

Samples in this kit were generated procedurally inside the MAP2 repository for launch-ready factory content.
Each instrument ships with 3 velocity layers and 2 round-robin alternates. Closed and open hi-hats share choke groups.
