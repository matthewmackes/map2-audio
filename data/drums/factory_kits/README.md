# MAP2 Factory Drum Kits

This directory contains purpose-generated launch kits for the MAP2 drum machine.

- `standard_rock`: acoustic rock layout with room and overhead slots
- `electronic_808`: 808-inspired electronic layout
- `electronic_909`: 909-inspired hybrid layout
- `jazz_brush`: brush-oriented jazz layout

All bundled samples are generated in-repo and released as CC0-1.0.
See `SOURCING_MANIFEST.json` for machine-readable provenance and `scripts/validate_factory_drum_kits.py` for repeatable topology validation.
