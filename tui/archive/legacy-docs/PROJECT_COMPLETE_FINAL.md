## 🚀 LIVE SHORTCUTS NOW IN TUI

```
Commands:
  Ctrl+Shift+P  → Command palette (search)
  Ctrl+F        → Search
  F1            → Help
  F2            → Diagnostics
  F10           → Performance monitor
  Ctrl+T        → Cycle themes (10 available)
  
Undo/Redo:
  Ctrl+Z        → Undo (100 history)
  Ctrl+Shift+Z  → Redo
  Ctrl+Y        → Redo (alt)

Layouts (switch instantly):
  Alt+1         → Compact
  Alt+2         → Normal
  Alt+3         → Wide
  Alt+4         → Fullscreen
  Alt+5         → Sidebar Left
  Alt+6         → Sidebar Right

Tabs (unchanged):
  1-9, 0        → Jump to tab
  Left/Right    → Navigate tabs
```
