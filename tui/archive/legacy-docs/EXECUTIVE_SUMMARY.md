## 💬 USER GUIDE PREVIEW:

**Getting Started (2 minutes):**
```bash
cd /home/mm/map2-audio
./tui.sh
```

**Explore:**
- Press 1-7 to switch tabs
- Press Ctrl+T to change theme
- Press F1 for help
- Press q to quit

**Pro Tips:**
- Ctrl+B toggles sidebar
- Alt+Left/Right for breadcrumb navigation
- Ctrl+Z for undo
- Ctrl+Shift+P for command palette
