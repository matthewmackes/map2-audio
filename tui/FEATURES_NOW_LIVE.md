
### Performance
```
Press: F10
Result: Performance monitor shows FPS, bottlenecks

Result: Health & diagnostics dashboard opens
```

### Customization
```
Press: Ctrl+T
Result: Theme cycles to next (10 available)

Press: Alt+1
Result: UI switches to Compact layout

Press: Alt+2
Result: UI switches to Normal layout

Press: Alt+3
Result: UI switches to Wide layout

Press: Alt+4
Result: UI switches to Fullscreen mode
```

### Safety
```
Press: Ctrl+Z
Result: Last action undone (100-action history available)

Press: Ctrl+Shift+Z
Result: Redoes the action
```
